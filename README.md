# Cashflow Harian

Aplikasi front-end statis untuk mencatat, memantau, dan menganalisis cashflow harian.

## Teknologi

- HTML native
- Tailwind CSS Play CDN
- JavaScript native
- CSS native seperlunya

## Menjalankan

Jalankan local server sederhana dari folder project, lalu buka `index.html` melalui browser.
